Important simulation note. This is a teaching model, not a live AI service. It uses transparent, hand-built concept features and keyword overlap instead of a trained embedding model, and it assembles an extractive answer instead of calling an LLM. Real RAG systems typically use learned embeddings, a vector database or search index, and an actual language model. This demo runs locally in your browser and sends no data to a server.
